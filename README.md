# Analisis Pendapatan Transaksi POS

## Deskripsi
Proyek ini menganalisis pendapatan transaksi Point of Sale (POS) pada tahun 2024 dan 2025 menggunakan Python dan Jupyter Notebook.

## Tahapan Analisis
- Membaca dataset transaksi.
- Memeriksa dan menangani missing value.
- Memperhitungkan jumlah barang, harga satuan, diskon, dan status transaksi.
- Menghitung pendapatan tahunan 2024 dan 2025.
- Membuat visualisasi pendapatan dalam bentuk grafik batang.

## Hasil
- Pendapatan 2024: Rp387.205.875
- Pendapatan 2025: Rp257.697.450

## Tools
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
