# Visualisasi Data Transaksi POS 2024-2025

Tugas PSD: visualisasi data transaksi POS menggunakan matplotlib.

## Isi
- A. Penjualan per bulan tahun 2025
- B. 10 produk terlaris tahun 2025
- C. Proporsi transaksi berhasil vs gagal/batal tahun 2025
- D. Hubungan jumlah beli dengan diskon

## Cara menjalankan
1. Buka `visualisasi_psd.ipynb` di Google Colab
2. Upload `paket_a_transaksi_pos_2024_2025.csv`
3. Run all

## Catatan
Data dibersihkan dulu (duplikat, format tanggal/harga, outlier jumlah).
